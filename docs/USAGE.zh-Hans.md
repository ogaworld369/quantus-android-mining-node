# 使用指南

**语言：** [English](USAGE.md) · [日本语](USAGE.ja.md) · 简体中文 · [Español](USAGE.es.md) · [हिन्दी](USAGE.hi.md) · [العربية](USAGE.ar.md) · [한국어](USAGE.ko.md) · [Русский](USAGE.ru.md) · [Français](USAGE.fr.md)

本应用在 Android 手机上运行 Quantus Network（QTC 主网）的**全节点**。它同步区块链、自行验证每一个区块，并向对等节点中继数据。默认以非验证者方式运行；也可以挖矿，但这是一个默认关闭的可选项（见下文**挖矿**一节）。它**没有钱包**，从不接触助记词——它唯一可能保存的秘密，是您自己粘贴进来的挖矿奖励 Inner Hash。

> 当前状态：v4.2.4 已发布（2026-11-17，当前版本）。这是针对 v4.2.3 外部审核的安全修复版本：应用现在从节点自身的启动输出中获取其 RPC 地址和身份，并在每次轮询时进行核对；显示名称仅在遥测开启时才传给节点；mDNS 和指标端点已关闭；迁移确认编号改用迁移自身的秘密作为密钥（v4.2.3 于 2026-11-17 发布，是重新构建随附二进制文件的维护版本）。签名 APK 已在 [GitHub Releases](https://github.com/ogaworld369/quantus-android-mining-node/releases) 上提供，并附带 SHA-256 校验和。此前的测试版本由维护者直接提供。

## 系统要求

- Android 12 或更高版本，arm64 设备
- 可用存储空间：节点数据库经过修剪（仅保留最近 256 个区块），体积较小。实测（Pixel 9a，完整同步后，2026-11-05）：总计 1.30 GB（应用 96 MB + 节点数据 1.20 GB）。作为参考，请预留至少约 3 GB 可用空间
- 互联网连接。首次同步强烈建议使用 Wi-Fi（见下文）

已验证设备：**运行 GrapheneOS 的 Pixel 9a**。其他设备预计可以运行，但尚未验证。如果您在其他机型上尝试，请通过 GitHub Issue 报告结果（无论成功与否）——已验证列表正是靠这些报告不断扩充的。

## 安装

1. 从 [GitHub Releases](https://github.com/ogaworld369/quantus-android-mining-node/releases) 获取 APK 文件（安装前请核对随发布提供的 SHA-256 校验和）。
2. 用“文件”应用打开 APK，Android 询问时允许从该来源安装。
3. 安装后打开 **Quantus Node**。

## 首次运行与初次同步

1. （可选）先设置**显示名称**和**遥测**选项（见“设置”）。设置变更需要重启节点（停止 → 启动）才能生效。
2. 点击**启动节点**。
3. 状态会显示**同步中**，最佳区块向最高区块攀升。在 Pixel 9a 上，从创世区块开始的首次同步约为每秒 50 个区块——请预计**约 2 小时**。同步完成后，大约每 12 秒到达一个新区块，状态变为已同步。
4. 首次同步期间，请尽量让手机**保持充电并连接 Wi-Fi**。通过移动数据同步也可以，但会下载大量数据且耗电明显更多（实测：移动数据同步时 30 分钟约消耗 11% 电量）。同步完成后的持续负载很小。

无需一直开着应用。节点作为前台服务运行：关屏或使用其他应用时仍会继续运行，运行期间会显示常驻通知。停止后再启动，同步会从中断处继续——已下载的链数据保存在设备上。

## 界面说明

应用底部有三个标签页：主页、连接、会员卡。节点详情和设置从主页进入。

- **主页** — 最佳区块、节点状态（已停止／启动中／同步中／已同步／失败）和一个主按钮。节点运行期间，还会显示已连接的对等节点数、本次运行时间和当前 QTC 价格。如果启动失败，主页会将其显示为失败并提供重试按钮，而不是普通的停止；如果您更改的设置尚未生效，主页会显示查看该设置的链接
- **连接** — 生动呈现本节点网络图景的界面：所连接的对等节点，以及本机记录的检查点回响。这里展示的是连接关系，而不是用来攀比的数字——没有排名
- **节点详情** — 最佳区块 / 最高区块（您的节点所在位置与已知网络顶端的对比）、同步差距、对等节点数和运行时间，以及**诊断**部分：退出代码、服务备注、每次启动尝试的记录和**分享日志**（见下文）。节点停止时，此界面显示的是您的累计轨迹记录，而不是上一次运行的数值
- **会员卡** — 您的会员卡：会员编号（设备 ID）和本机记录的三个数字——首次检查点日期、检查点数量、最长连续天数。记录仅保存在本机，永不上传，也不具有金钱价值——它只是您自己的贡献足迹，是否出示由您决定
- **设置** — 以下设置，按页面排列成一个中心页。应用版本显示在**关于本应用**页面中；同页还列出了内置节点和矿工程序的**开源许可证**

## 设置

- **在遥测中显示**（默认关闭）— 开启后，您的节点名称和实时状态将在官方遥测页面 telemetry.quantus.com 上公开可见。仅在您希望被列出时开启。从下次节点启动时生效（停止 → 启动）。
- **显示名称** — 节点在遥测中显示的名称，在对话框中编辑。节点仅在 **在遥测中显示** 开启时使用该名称（此时已连接的对等节点也能看到它）；遥测关闭时，节点以默认名称 `quantus-android-node` 运行。留空则使用默认名称。从下次节点启动时生效。
- **语言** — 跟随设备设置，或从 9 种语言中选择（日语、英语、简体中文、西班牙语、印地语、阿拉伯语、韩语、俄语、法语）。选择后立即生效。
- **记录我的活动（DePIN）**（默认关闭）— 开启后，应用会把节点的在线与中继工作的签名记录保存在本机（每 10 分钟一个检查点）。记录不会自行发送到任何地方；您可以从“设置”将其导出为证明包文件并自行分享。关闭后停止记录，已有记录保留在设备上
- **锁定设置** — 将上面的设置（遥测、显示名称、语言和活动记录）和挖矿设置（挖矿开关与 Inner Hash）锁定，以免手机在持续运行节点时被误触更改。这只是防误触功能，没有 PIN 码，节点的启动与停止永远不会被锁定。需要更改设置时，关闭 **锁定设置** 即可。
- **挖矿**（默认关闭） — 节点也可以用内置的官方矿工程序在本设备上挖矿。需要先准备奖励 Inner Hash；见下文**挖矿（可选）**。

设置不会自行重启节点。如果在节点运行期间更改了遥测（或在遥测开启时更改了显示名称），被更改的项目会在设置中标记为尚未生效，主页也会显示查看待生效设置的链接；更改将在下次节点启动时（停止 → 启动）生效。

**分享日志** 位于 **节点详情 → 诊断** 中：它以文本形式分享节点日志，报告问题时请附上它。在公开场合粘贴日志前，请先检查内容：日志中可能包含本节点的公网 IP 地址和对等节点信息。分享对话框可以对显示名称、应用私有路径以及日志中的 IP 地址进行掩码处理（默认开启）：包括本机自身的接口地址、节点通过对等节点获知的外网地址和对等节点的地址（环回地址保持可读）。

## 存储

**设置 → 存储** 显示应用占用的空间，共六项数字：**链数据库**、其余的**节点数据**、**日志**、**活动记录**（DePIN）、**合计**和**本设备可用空间**。节点运行期间数字会不断变化，请将其视为估算值。

该页面只有一个操作：**删除链数据库并重新同步**。它只删除链数据库——即本设备迄今已同步的区块数据。节点的网络密钥、挖矿设置和保存的 Inner Hash、您的 DePIN 身份及其记录、轨迹记录、日志和应用设置都会保留。此操作只能在节点停止时使用，且无法撤销：下次启动节点时，同步将从头开始，需要时间和流量（Pixel 9a 上约 2 小时）。

## 价格

主页显示当前 QTC 价格，应用约每小时从 **CoinGecko**（api.coingecko.com）获取一次。获取**默认开启**；开关位于价格面板（点按主页上的价格）和 **设置 → 来自外部的信息** 中。获取时只发送价格查询和一个标明应用及其版本的 User-Agent（`QuantusNode/<version>`）——不会发送任何节点信息、会员编号或记录——但 CoinGecko 可以看到本设备的 IP 地址，任何您连接的服务器都是如此。关闭开关后将不再获取：价格行显示“关”，面板显示一条横线——即使之前获取过价格也不会保留显示。

## 挖矿（可选）

本应用也可以使用内置的官方矿工程序，在这台手机上挖矿。挖矿**默认关闭**，关闭时节点的运行方式完全相同。开启后，节点将以验证者身份启动，奖励归您所有，而不是归本应用。

**开启挖矿之前，您需要先准备好奖励用的 Inner Hash。** 奖励不会支付到普通地址：协议规定，奖励支付到一个由名为 Inner Hash 的秘密导出的**虫洞（wormhole）地址**。

获取 Inner Hash 的方法：

- 在电脑上运行官方节点的命令 `quantus-node key quantus --scheme wormhole`。它会输出三个值：**Address**（奖励的接收地址）、**Inner Hash**（本应用需要的值）和 **Secret phrase**（您的备份——请离线妥善保管）。
- 如果您已经在使用官方钱包，也可以从它的助记词导出同样的三个值：在同一命令后加上 `--words`，并在提示时输入助记词——只能在电脑上输入，绝不要输入到本应用中。使用同一助记词的钱包里，奖励会自动出现。
- 或者，在官方 Quantus 钱包应用中，打开 **Encrypted Account** 的菜单并选择 **Inner Hash**：应用会直接显示该账户的 Inner Hash，奖励将支付到该 Encrypted Account。无需电脑，助记词也不会离开钱包应用。

然后在本应用中：

1. 打开**设置 → 挖矿**，粘贴 **Inner Hash** 的值（形如 `0x` 后跟 64 位十六进制数字）。只能输入 Inner Hash，绝不要输入助记词或私钥：Inner Hash 会被写入本设备产出的每一个区块，并成为公开信息。
2. 应用会显示节点针对您的 Inner Hash 报告的奖励地址。在信任它之前，请与同一来源的地址核对——工具输出的 **Address**，或钱包应用中的 **Encrypted Account**。
3. 开启挖矿，然后重启节点（停止 → 启动）。挖矿设置从下次节点启动时生效。

**保存前请仔细核对 Inner Hash。** 如果填错，奖励将被支付到那个错误的地址，且无法追回。保存的值只存放在本设备上，应用不会在屏幕、日志或共享文本中显示它。

**工作线程与发热。** CPU 工作线程可以选择 1、2、4 或自动（默认为 2；始终为节点本身留出一个核心）。线程越多，发热和耗电越大。如果手机发热，挖矿会在系统的“中等”热等级下自动减弱，并在“严重”或更高等级时在本次会话的剩余时间内停止——手机永远不会被逼到极限。

**请抱有切合实际的预期：** 以手机的算力，找到一个区块的预期等待时间非常长，远超任何测试时长。这里的挖矿是一种参与方式，而不是一种赚钱方式。

## 迁移到新设备

您的 DePIN 身份及其记录可以迁移到新手机。在两台设备上都打开 **设置 → 设备间迁移**；简易方式只需要一个文件：

1. 在**旧设备**上，点按 **创建简易迁移文件**。应用会创建该文件并只显示一次**迁移代码**——请记下来。此时旧设备上的记录会停止。
2. 把文件传到**新设备**（方式不限）。在新设备上点按 **导入迁移包**，选择文件并输入迁移代码。
3. 新设备会验证该包，并显示即将接管的身份：设备 ID、检查点数量以及第一条和最后一条记录的日期。请核对这些值，然后点按 **用简易迁移确认**。此后该身份归这台设备所有，可以在这里开始记录。
4. 然后新设备会显示一个 8 位**确认编号**。在旧设备上点按 **输入确认编号：删除本设备的密钥** 并输入它——只有编号匹配时旧密钥才会被删除。之后，请把还留着的迁移文件也删除掉。

在第 4 步完成之前，身份存在两份副本。**请把迁移文件当作密钥对待**：其中包含用迁移代码加密的身份种子，任何同时拥有文件和代码的人都可以接管该身份及其全部历史。请尽量分开传递两者，绝不要把任何一个发布到公开场合。如果文件从未到达新设备，在旧设备上 **取消简易迁移** 可以让记录在旧设备上恢复——但一旦新设备已经导入，绝不要取消。

迁移前需要知道两点：两台设备都需要 v4.2.4 或更高版本（旧版本无法读取新格式的数据包）；迁移包上限为 16 MiB，约可容纳 19,900 个检查点。如果您的历史记录超过这一上限，导出时会明确提示，而不会生成新设备无法接收的文件。

在同一页面的 **其他操作** 下，还有更严格的分步迁移：两台设备不使用单个确认编号，而是一个文件接一个文件地交换暂存通知、确认许可、回执和完成确认。

## 日常运行

- 节点只会在以下情况停止：点击**停止节点**、强制停止应用、或重启手机。
- 重启手机后，请打开应用再次点击**启动节点**——开机自动启动尚未实现。
- 某些厂商的 Android 版本（Samsung、小米等）省电策略较激进，可能会停止后台服务。如果节点总是被停止，请在系统设置中将本应用排除在电池优化之外。
- 把闲置手机 24 小时插着电使用？请时不时检查电池状态——老化的锂电池可能会鼓胀。请把手机放在通风处；如果设备提供充电上限设置，建议开启。

## 遇到问题时

- **节点立即退出** — 打开**节点详情 → 诊断 → 分享日志**，将日志附在 GitHub Issue（缺陷报告模板）中发送。日志记录了每次启动尝试及其结束原因。
- **对等节点一直为 0** — 检查网络连接，然后停止 → 启动一次。
- **同步停滞（网络在前进，但您的最佳区块不动）** — 应用检测到这种形态后会自行重启节点（24 小时内最多 3 次）。如果反复出现，换到稳定的 Wi-Fi 后再停止 → 启动一次
- **您的节点没有出现在遥测中** — 确认遥测选项已开启，且开启后重启过节点。（列表显示已确认可用：维护者自己的节点已出现在官方列表中。）
- **关于存储** — 数据库按设计修剪为最近 256 个区块。卸载应用会删除数据库和节点的身份密钥——同时还会删除保存的 Inner Hash 以及您的 DePIN 身份和它的全部记录。重新安装会以新身份重新同步，因此如果希望保留记录，请先将其迁移到新设备（见上文 **迁移到新设备**）。

问题、设备报告和建议都欢迎提交 GitHub Issue。安全问题请按 [SECURITY.md](../SECURITY.md) 的流程报告，不要发公开 Issue。
